Planned structure
-----------------
Shared libraries:

 - *libdn:* Image processing & CMM

Servers:

 - *dnthumbd:* Thumbnailing service
 - *dndbd:* Database service
 - *dntagd:* ML tagging service
 - *dnvfsd:* Virtual File System service
 - *dnimaged:* Image decoding service (if separation becomes desirable)

User interfaces:

 - *dn:* Vulkan frontend
 - *dnweb:* Web frontend to the database
 - *dntui:* notcurses frontend (with limited features)
