Name
----
dn - Image browser and viewer

Synopsis
--------
*dn* [_OPTION_]... [_PATH_ | _URL_]...

Description
-----------
*dn* is a general-purpose image browser and viewer: pass it a directory path
or URL to open it for browsing, or pass an image to open it for viewing.
If multiple arguments are passed, they'll be opened in separate windows.

For more information concerning usage, press *F1* in the application to open
the _User Guide_.

Options
-------
*--mode*=_view|browse|cropjpeg|commander_::
	Select the application to open.  View and Browse are the image browser's
	two faces; Browse preselects files in their directory, used to implement
	the "Open Containing Folder" feature of certain applications.
	JPEG Cropper and Commander are unimplemented.

*--invalidate-cache*::
	Invalidate the wide thumbnail cache, removing thumbnails for files that can
	no longer be found.

*--list-supported-media-types*::
*--list-supported-extensions*::
	Output supported media types or file extensions and exit.

*-V*, *--version*::
	Output version information and exit.
